## 2. P1 — CHK-13/14 동시 이중 표출 (재현 확정)

- 프로브: staleTerms=`["적응형모델"]` + 혼입 문서(도면설명·부호표에 구세대 명칭구) → **CHK-13 2건(HIGH, 섹션별) + CHK-14 2건(MEDIUM, 섹션별) = 4줄**. 같은 (정규화 용어, 섹션) 쌍이 2계층에서 각각 보고됨 — 예비 프로브(실측 6+3=9줄)와 **일치**.
- 원인: 두 검사는 소스가 다를 뿐(이력 기반 vs 소급 휴리스틱) 결함 실체가 같고, 3.1b 설계 시 "CHK-13 사각을 메우는 상보"로 도입되어 **겹침 시 억제 규칙을 두지 않았다**(당시 스코프 판단 — 결함은 아니고 설계 공백).
- 영향: 패널 가독성 저하(같은 결함 2줄×섹션수). 카운트 왜곡: 실측 표에서 "9줄"처럼 결함 수가 부풀려 보임.
- **권고 (결정필요 ②)**: CHK-14 발화 직전, 해당 청크 `c`가 `_activeStaleTerms()`에 존재하고 CHK-13이 같은 섹션에 이미 발화했으면 그 (청크,섹션) 건을 억제(HIGH 1건만 잔존). 구현 ~3줄(CHK-13 발화 시 `term|섹션` Set 기록 → CHK-14에서 조회). staleTerms 빈 소급-단독 상황엔 영향 0.
