## 1. 신설: Stat 4 카드 (현재 없음 → 추가)

`#patent-sub-spec` **최상단**(액션/목록 행 위)에 통계 4카드 신설.

- 마크업·CSS는 시안의 `.stat-grid` / `.stat-card` 그대로 이식 → `patent.css`에 `.pt-stat-grid`, `.pt-stat-card`, `.pt-stat-value` 등으로 명명.
- **데이터 바인딩** (patent.js에서 채우도록 빈 id 부여):
  | 카드 | 값 id | 산출 |
  |---|---|---|
  | 전체 사건 | `dashStatTotal` | 사건 목록 총 건수 |
  | 작성 중 | `dashStatWriting` | status가 작성 중인 건수 |
  | 검토 대기 | `dashStatReview` | status가 검토 대기인 건수 |
  | 완료 | `dashStatDone` | status가 완료인 건수 |
- patent.js의 사건 목록 렌더 함수 끝에 위 4개 카운트를 계산해 `textContent` 채우는 코드 추가(데이터 소스는 기존 목록 배열 재사용 — 신규 API 호출 금지).
- **상태값이 실제로 무엇인지** 확인 필요: 현재 `projects` 데이터의 status 필드 enum을 patent.js에서 확인하고, 위 4분류에 매핑. (만약 실제 상태가 다르면 카드 라벨을 실제 enum에 맞춰 조정 — 임의 생성 금지)

## 2. 색 토큰 매핑 (시안 → 운영 semantic)

시안은 `--dt-*` 직접 사용했으나, **운영 코드는 `--color-*` semantic 우선**(common.css 브릿지 일관성). 아래로 치환:

| 시안 (`--dt-*`) | 운영 (`--color-*`) |
|---|---|
| `--dt-brand` | `--color-primary` |
| `--dt-brand-hover` | `--color-primary-hover` |
| `--dt-brand-light` | `--color-primary-light` |
| `--dt-brand-pale` | (없음) → `--color-primary-light` 또는 신규 안 만들고 `--dt-brand-pale` 직접 |
| `--dt-success` / `-light` | `--color-success` / `--color-success-light` |
| `--dt-warning` / `-light` | `--color-warning` / `--color-warning-light` |
| `--dt-g900/700/500/...` | `--color-text-primary/secondary/tertiary`, `--color-border`, `--color-bg-*` (semantic 우선, 없으면 `--dt-gN` 직접) |
| `--dt-r-lg` / `-sm2` | `--radius-lg` / (8px는 `--dt-r-sm2`, STEP1에 있음) |
| `--dt-sh-sm` | `--shadow-sm` |
| `--dt-font` | `--font-family` |

> 폰트·radius·shadow는 common.css에 semantic 별칭이 있으니 그걸 우선 사용.

## 3. 상태 배지 (신규 컴포넌트)

사건 상태를 색 배지로. `patent.css`에 추가:
```css
.pt-badge { display:inline-flex; align-items:center; gap:4px; height:24px; padding:0 10px;
  border-radius:var(--radius-full); font-size:var(--font-size-small); font-weight:700; }
.pt-badge .dot { width:5px; height:5px; border-radius:50%; background:currentColor; }
.pt-badge.is-writing { background:var(--color-primary-light); color:var(--color-primary-hover); }
.pt-badge.is-review  { background:var(--color-warning-light); color:var(--color-warning); }
.pt-badge.is-done    { background:var(--color-success-light); color:var(--color-success); }
.pt-badge.is-prov    { background:var(--color-bg-secondary); color:var(--color-text-tertiary); }
```
- patent.js의 행 렌더에서 status→클래스 매핑(`is-writing`/`is-review`/`is-done`) 적용. (기존에 status를 어떻게 표시했는지 확인 후 그 자리에 배지로 교체)

## 4. 사건 목록 테이블 (구조 보존 + 스타일 교체)

- **기존 `<table>` / `<thead>` / `<tbody id="dashProjectList">` 골격·id 유지** (patent.js가 `dashProjectList`에 행을 그림).
- 변경은 **CSS 클래스와 셀 내부 구조**만:
  - thead → `.pt-thead`(배경 `--color-bg-tertiary`, 라벨 `--color-text-secondary`)
  - 행 hover → `--color-primary-light` 배경
  - 사건명 셀: 제목(`.pt-case-name`) + 부제(`.pt-case-sub`, 장치유형·청구항 수) 2줄 구조. **부제 데이터가 기존에 있으면** 표시, 없으면 생략(임의 생성 금지).
  - 사건번호 → `.pt-case-no`(mono, `--dt-mono`)
  - 작업 칼럼 → `.btn.btn-outline.btn-sm` "열기" (기존 버튼 클래스 재사용)
- **인라인 스타일 제거**: 현재 `<th style="padding:...">` 등 인라인을 전부 클래스로 이전.

## 5. 액션 컬럼 (좌측 240px) — 구조 유지, 스타일만

- 기존 좌측 240px 패널 구조 유지. 인라인 스타일 → 클래스(`.pt-action-col`, `.pt-panel-title`, `.pt-ref-card`).
- 버튼은 기존 `.btn .btn-primary .btn-full` 등 **운영 클래스 재사용**(시안의 `.btn-md`는 운영 버튼 높이 토큰에 맞춤).
