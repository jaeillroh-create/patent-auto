# 분할출원 핵심 원칙

## 1. 신규사항 추가 금지

- 분할출원의 청구항은 **원출원의 최초 명세서 및 도면에 기재된 범위**를 벗어나서는 안 된다 (특허법 제52조).
- 원출원에 명시적 또는 자명하게 기재되지 않은 구성요소, 한정사항, 수치범위를 새로 추가하는 것은 절대 금지한다.
- 청구항 생성 시 모든 구성요소가 원출원 명세서에서 출처(문단 번호 또는 도면 번호)를 특정할 수 있어야 한다.
- 상위 개념화(일반화)는 원출원에 그 상위 개념이 직접 기재되었거나 자명하게 도출되는 경우에만 허용한다.

## 2. Basis(명세서 뒷받침) 절대 보존

- 분할 청구항의 모든 구성요소는 원출원 명세서의 **구체적인 기재 부분**과 1:1로 대응되어야 한다.
- 검증 단계에서 각 청구항 구성요소별로 명세서 뒷받침 근거(해당 문단, 도면 참조)를 반드시 제시한다.
- 뒷받침 근거가 불명확한 구성요소는 청구항에 포함하지 않거나, 명세서 기재에 맞게 수정한다.
- 독립항뿐 아니라 종속항의 추가 한정사항도 동일한 수준의 basis 검증을 적용한다.

## 3. 추가 구성 출처 제한

- 분할 청구항에 추가되는 구성요소는 오직 다음 출처에서만 가져올 수 있다:
  - **원출원 명세서 본문** (발명의 설명, 실시예)
  - **원출원 도면 및 도면의 간단한 설명**
  - **원출원의 기존 종속항** (원출원에서 삭제/포기된 청구항 포함)
- 의견서(OA) 대응 과정에서 심사관이 인용한 선행기술 문헌의 내용을 분할 청구항에 직접 반영하는 것은 금지한다.
- 출처가 불분명한 기술 용어나 표현은 원출원의 용어를 그대로 사용하여 일관성을 유지한다.

## 4. 바로 등록결정 전략

- 분할출원의 목표는 **추가 OA 없이 바로 등록결정**을 받는 것이다.
- 원출원의 거절이유통지(OA)에서 등록 가능성이 인정된 종속항을 우선적으로 독립항화한다.
- 심사관이 명시적으로 특허성을 인정한 구성요소 조합을 중심으로 청구항을 구성한다.
- 청구항의 명확성을 최대화하여 기재불비(제42조 제4항) 거절을 사전에 방지한다.
- 불필요하게 넓은 권리범위보다는 **확실한 등록**을 우선시하되, 핵심 기술적 특징은 반드시 포함한다.

## 5. 출처(단락번호) 표시 필수

- 분할 청구항의 **모든 구성요소**에 대해 원출원 명세서의 해당 단락번호(예: [0023], [0045]) 또는 도면번호(예: 도 3, 도 5a)를 반드시 병기한다.
- 검증 결과 출력 시 각 구성요소 옆에 `[출처: 단락 XXXX]` 또는 `[출처: 도 X]` 형식으로 근거를 명시한다.
- 단락번호를 특정할 수 없는 구성요소는 청구항에 포함하지 않는다.
- 복수의 단락에 걸쳐 기재된 경우 관련 단락번호를 모두 나열한다 (예: `[출처: 단락 0023, 0045-0047]`).

## 6. 할루시네이션(거짓 생성) 절대 금지

- 원출원 명세서에 **실제로 기재되지 않은 내용을 생성하거나 추론하여 청구항에 포함하는 것을 절대 금지**한다.
- LLM이 생성한 모든 구성요소는 원출원 명세서 원문과 대조 검증을 거쳐야 하며, 대조 불가 시 해당 내용을 즉시 삭제한다.
- 명세서에 없는 기술 용어, 효과, 수치, 동작 방식을 AI가 자체적으로 만들어내는 것은 신규사항 추가에 해당하므로 원천 차단한다.
- 검증 단계에서 원출원 명세서 원문 인용(직접 발췌)을 통해 할루시네이션 여부를 교차 확인한다.
